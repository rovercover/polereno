# Architectural concept imagery

All eight images were created with the built-in image generation tool for this project. No downloaded stock images or third-party project photographs are used. The scenes are illustrative, not depictions of real completed commissions. No images were used as claimed before-and-after evidence.

Final assets: `public/images/{name}-{640,1000,1600}.webp`. Original selected PNGs: `.assets-source/{name}.png`. Images were resized and encoded to WebP using Sharp, with no color filters or artificial overlays. All prompts use the `photorealistic-natural` category and an opaque background.

The site now animates these originals in real time: a slow camera move and subtle, spatially masked water distortion. This is a procedural cinemagraph effect, not generated footage of a real location. The original image files are unchanged. `reports/pool-motion.webm` is a six-second capture of the actual effect; the live site does not need to download video files. Visitors can pause the effect, and reduced-motion preferences disable it.
